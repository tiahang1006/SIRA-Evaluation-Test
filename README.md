# 🦠 SIRA Evaluation Test - GSoC 2025

This repository contains my completed evaluation test for the HumanAI Foundation GSoC project **Learning the Susceptible-Infected-Removed (SIR) Model**.

## 📋 Overview
- Simulate stochastic SIR epidemic outbreaks
- Clean and smooth the data for ML
- Train neural networks to fit SIR trajectories
- Use symbolic regression (PySR) to infer differential equations

## 🧠 Technologies
- Python 3.9
- PyTorch
- PySR (with Julia)
- NumPy, Pandas
- Jupyter Notebook

## 🚀 How to Run

1. Clone this repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start Jupyter Notebook:

```bash
jupyter notebook SIRA_evaluation_test.ipynb
```
